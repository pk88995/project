CSS教學

在這堂課程上面，你了解如何使用CSS設定用在HTML標籤上，以及設定連結顏色。

這章節你認識的CSS設定文字語法

  1. 文字顏色：color
  2. 文字大小：font-size
  3. 文字行距：line-height
  4. 文字字型：font-family
  5. 其它..

下列的emmet語法，哪一項是錯的？

  • ! = HTML5 環境
  • link:src = 匯入CSS (注意：影片提醒正確應為 link:css)
  • p*4 = 顯示4個p段落
  • h1 = 展開h1的開頭與結尾html標籤
  • lorem = 自動幫我們寫完網頁
